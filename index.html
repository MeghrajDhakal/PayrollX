Enterprise Architecture Features

Designed to withstand concurrent load, malicious input, and cross-tenant attacks

🛡️

Row-Level Tenant Isolation

Every SQLAlchemy query is scoped to org_id at the query layer. Cross-tenant IDOR attacks on payslip PDFs or employee records return 403/404.

⚡

Atomic Transactions & Idempotency

Payroll calculation runs inside short atomic transactions. Double-clicks or duplicate requests with an Idempotency-Key safely return the original result.

📄

Server-Side PDF Generation

High-fidelity, printable payslip PDFs generated in memory using ReportLab without holding database locks open during rendering.

🔐

Bcrypt & Session Invalidation

Passwords hashed with Bcrypt (12 rounds). Logging out clears the server-side session token, immediately rejecting any copied or stolen cookies.

📊

Observability & PII Masking

Emits structured JSON logs with correlation request_id and latency. Sensitive PAN, Aadhaar, bank details, and passwords are masked automatically.

🚀

Production WSGI & Migrations

Configured with Gunicorn gthread workers, connection pool tuning, and Alembic database migrations (Flask-Migrate).

Quick Start in 3 Commands

Run PayrollX locally with SQLite or connect to Managed PostgreSQL:

# 1. Clone repository & enter project
git clone https://github.com/MeghrajDhakal/PayrollX.git && cd PayrollX/My_Project

# 2. Install pinned dependencies & run migrations
pip install -r requirements.txt && PYTHONPATH=src flask db upgrade

# 3. Start the application (auto-opens browser at http://127.0.0.1:5000)
python launch.py
