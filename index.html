Enterprise Architecture Features

Designed to withstand concurrent load, malformed payloads, and cross-tenant attacks.

Row-Level Tenant Isolation

Every SQLAlchemy query is scoped to org_id at the query layer. Cross-tenant access attempts return 403/404.

Atomic Transactions & Idempotency

Payroll runs execute inside short atomic transactions; duplicate keys safely return the original response.

Server-Side PDF Generation

Printable ReportLab payslip PDFs generated in memory without holding open database locks.

Bcrypt & Session Invalidation

12-round Bcrypt hashing and server-side session tokens ensure logged-out cookies cannot be replayed.

Observability & PII Masking

Structured logs include correlation request_id and latency while automatically masking PAN, Aadhaar, and bank numbers.

Production WSGI & Migrations

Configured for Gunicorn workers, PostgreSQL/SQLite portability, and Alembic database migrations.

Quick Start in 3 Commands

Run PayrollX locally with SQLite or connect directly to Managed PostgreSQL.

# 1. Clone repository & enter project
git clone https://github.com/MeghrajDhakal/PayrollX.git && cd PayrollX/My_Project

# 2. Install pinned dependencies & run migrations
pip install -r requirements.txt && PYTHONPATH=src flask db upgrade

# 3. Start the application (opens browser at http://127.0.0.1:5000)
python launch.py
